## 🧾 2. Notas-fiscais

**Java · Maven · Sankhya ERP · Google Cloud Vision · OCR · FTP · HTTP**

Sistema de automação para processamento de documentos e integração com o ERP Sankhya.

**Principais funcionalidades:**

* 📥 Recepção de arquivos por FTP.
* 🖼️ Processamento de imagens de documentos.
* 🔎 Extração de texto utilizando OCR.
* 🧠 Interpretação e processamento das informações extraídas.
* 🔗 Consultas e operações de integração com o Sankhya ERP.
* 📂 Organização e movimentação de arquivos durante o processamento.
* ⚙️ Automação de fluxos operacionais envolvendo documentos fiscais, bombas e vistorias.

**Fluxo simplificado:**

```text
Entrada de arquivos
        ↓
       FTP
        ↓
Processamento de imagens
        ↓
Google Cloud Vision OCR
        ↓
Interpretação dos dados
        ↓
Integração com Sankhya ERP
        ↓
Consulta e registro de informações
        ↓
Organização dos arquivos
```

O projeto reúne automação, processamento de documentos e comunicação entre sistemas empresariais.

## ⚔️ 3. Servidor Bridge

**Java 8 · Spigot 1.8.8 · Bukkit API · YAML**

Plugin de Minecraft com implementação de mecânicas do minigame The Bridge e funcionalidades administrativas.

**Principais funcionalidades:**

* 🎮 Partidas 1v1, filas e seleção de mapas.
* 🔴🔵 Gerenciamento das equipes Azul e Vermelha.
* 🏆 Pontuação, condições de vitória e encerramento de partidas.
* 🌍 Gerenciamento de mundos para partidas.
* ⚔️ Kits, inventários, equipamentos e espectadores.
* 🛡️ Grupos, permissões e sistemas de punição.
* 🔍 Verificação personalizada de alcance de ataques.
* 📊 Scoreboard, títulos, sons e menus interativos.

O projeto explora gerenciamento de estados, eventos, jogadores e mundos dentro da API Bukkit.

> O código possui pontos que ainda precisam de configuração, revisão e testes antes de ser considerado pronto para produção.

## 📍 4. Localizacao-Obra

**PHP · JavaScript · Sankhya ERP · Geolocation API · Fabric.js**

Aplicação web para registro de inspeções de obras integrada ao ERP Sankhya.

**Principais funcionalidades:**

* 🔐 Autenticação por sessão.
* 🏗️ Consulta de obras, clientes e status.
* 📋 Formulários e questionários de vistoria.
* 📝 Registro de observações.
* 📍 Captura da localização geográfica pelo navegador.
* ✍️ Captura de assinatura desenhada em tela.
* 🖼️ Geração da assinatura em formato PNG.
* 🔗 Envio dos registros para o Sankhya por API.

**Fluxo simplificado:**

```text
Autenticação
     ↓
Consulta da obra
     ↓
Preenchimento da vistoria
     ↓
Questionário e observações
     ↓
Localização e assinatura
     ↓
Finalização do registro
     ↓
Integração com Sankhya
```

## 🎮 5. Amethyst2D

**Java · AWT · Swing · Graphics2D · BufferStrategy**

Biblioteca própria para desenvolvimento de aplicações gráficas bidimensionais em Java.

O projeto busca oferecer componentes reutilizáveis para aplicações 2D, com foco em renderização, animação, movimentação e interação.

**Principais componentes e recursos:**

* 🪟 Gerenciamento de janelas.
* 🎨 Renderização gráfica e double buffering.
* 🖼️ Manipulação de imagens.
* 👾 Sprites e spritesheets.
* 🎞️ Animações.
* ⌨️ Captura de entradas do teclado.
* 🎯 Sistema de ações.
* 💥 Detecção de colisão AABB.
* 🔄 Rotação e movimentação.

**Estrutura principal:**

```text
Object
  └── Imagem
        └── Animacao
              └── Sprite
```

O repositório também possui uma aplicação de demonstração que utiliza a biblioteca.
